# Golden test vectors for the AmsDots motion packet (docs/protocol.md).
# Written with an independent encoder (Python struct), so they check the Kotlin
# codec and the Rust codec against the spec rather than against each other.
#
# Format: blocks separated by blank lines.
#   vector: <name>            a valid packet
#   hex: <bytes>              the packet, hexadecimal, spaces ignored
#   seq / first_sample_ms     header fields
#   gravity_mg: x y z         header gravity
#   speed_cm_s: n | none      version 2 header: GPS speed in cm/s; absent (version 1) or none = no speed
#   fix_age_ms: n             version 2 with a speed: first sample time minus fix time, ms (negative = newer)
#   sample: ax ay az gx gy gz one line per sample (mm/s^2, mrad/s)
#
#   invalid: <name>           a packet that must be rejected
#   hex: <bytes>
#   error: <kind>             too_short | bad_version | bad_length | bad_count
